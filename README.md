# 微生物实验室主要致病菌在不同培养基上的菌落形态交互式图谱

11 种食源性致病菌 × 21 种培养基 = 231 个组合的生长情况比对与 99 个组合的 232 张菌落实拍照片，支持按菌株、培养基交互查询。

## 功能

- 生长热图：生长 🟢 / 弱生长 🟡 / 不生长 🔴 / 未实验 ⚪，点击查看菌落照片大图
- 每张照片标注：培养基来源（供应商）与照片作者（By 署名）
- 会员注册登录（邮箱验证）、投稿补充实验数据，经管理员审核后生效
- 忘记密码支持邮件重置
